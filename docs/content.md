**权威表要定期重导**（`tools/dump_catalog.py` / `dump_relics.py` / `dump_potions.py`）。
它不是常量，是「这个存档发现了多少」的快照 —— 对着旧快照会**高估**自己的覆盖率
（2026-08-30 重导时牌表一次涨了 22 张）。分子（建了几件）和分母（发现了几件）
是两件事，**只有前者是工作量**。

（**彼岸咆哮 2026-09-06 建掉了** —— 它欠的"回合末从消耗堆里自己打出来"
现在是 `EXHAUST_END_AUTOPLAY` 一行表。它是这一批里第一个被建掉的，
起因是一条**假装成规则错误的内容缺口**：原始力量+ 该把它变成巨石+，

**心灵腐化**欠抽牌数修饰器（清晰药水同一个洞）· **心灵震慑**欠「伤害 = 抽牌堆张数」
这个 `Op` **且**欠固有（Innate）· **未掘宝石**欠重放（Replay）关键字。

### `ModifyXxx` 那一族：**不需要新表，需要遗物把状态交给实体**

「改一个正在算的数值」的遗物（打击木偶/钢笔尖/纸蛙/化学物X…）曾经被记成
"现有三类表里没有位置，硬加就得往 `damage.rs` 塞 `if 有没有某遗物`"。
**2026-09-06 钢笔尖建掉了，出路是不往那边走**：

> 遗物把自己的状态交给**玩家实体**（`RelicDef::private_status` + `counter_to`
> 给的 status），`damage.rs` 照旧**只认 status** —— 和它已有的十个乘区一模一样，
> 一个 `if 遗物` 都没有。

钢笔尖用了三个：`PenNib`（在场）· `PenNibCount`（跨战斗计数，走 `counter_to`
从观测的遗物面板灌）· `PenNibArmed`（这一次出牌翻倍，进 `PIPELINE_STATUSES`）。
计数在 `step::resolve_played_card` **结算之前**（[源码] `BeforeCardPlayed`），
乘区在 `damage::apply_modifiers`。同族剩下的 7 件照这个套路都建得进去。

## 内容从哪来

`get_compendium` 的 `card_library` **只有 id 和统计，没有卡面文本**，灌不了内容。
有文本的是 `GET /api/v1/wiki`，而且**同时给基础版和升级版** ——
`tools/dump_catalog.py` 走的就是这条路。它一次就纠正了 5 个照初代记忆填的 `ops_upg`
（欺凌+/烙印+/踩踏+/无情猛攻+/预备打击+）。敌人那边 `bestiary` 在 UI 里是锁的，
只能从 trace 反推，走 `tools/enemy_report.py`。

**"没实现"和"没验过"是两件事，后者的数字大得多。** 表里很多牌是 `[源码]` 灌进去的，
**第一次实战打出时对拍才会判它**。
